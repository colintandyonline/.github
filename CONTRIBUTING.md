# Contributing to CTDG

Start with the repository README and existing issues. For substantial changes, discuss the proposal first. Keep pull requests focused, document behaviour changes, include relevant tests and disclose limitations. Never include credentials, client information or private infrastructure details. Respect upstream licences and attribution. Contributions are reviewed on their merits; acceptance and delivery times are not guaranteed.

For questions and ideas, use the [community hub](https://github.com/colintandyonline/colintandyonline/discussions).
